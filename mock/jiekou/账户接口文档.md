## POST 分页查询

> Body 请求参数

```json
{
  "page": 1,
  "page_size": 10
}
```

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|body|body|object| 是 |none|

> 返回示例

> 200 Response

```json
{
  "code": 0,
  "data": {
    "page": 0,
    "page_size": 0,
    "data": [
      {
        "id": 0,
        "accountId": "string",
        "accountName": "string",
        "personIds": "string",
        "countryId": "string",
        "groupIds": "string",
```

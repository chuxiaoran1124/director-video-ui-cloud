# 字幕样式预览 · 前后端对接方案

> 更新时间：2026-04-13
> 视频格式：竖屏 9:16（典型分辨率 1080×1920）

---

## 一、整体交互流程

```
① 用户进入字幕配置页
        ↓
② 前端调用【预览帧接口】（仅调用一次）
   → 后端返回视频第2秒的帧图片（540×960 JPEG，base64编码）
        ↓
③ 前端把帧图片铺在 Canvas 背景上
   用户拖动滑块 / 选色 → Canvas 实时重绘字幕预览
   （纯前端渲染，零网络请求，即时响应）
        ↓
④ 用户点击「确认提交」
   → 前端把 subtitle_config 带上调用【提交接口】
        ↓
⑤ 后端异步处理视频，前端轮询结果（原有逻辑不变）
```

---

## 二、接口一：预览帧接口（新增）

### 请求

```
POST /api/video/subtitle/preview-frame
Content-Type: application/json
```

```json
{
  "video_url": "https://xxx.com/video.mp4",
  "frame_time": 2,
  "blur_subtitles": false,
  "blur_strength": 15
}
```

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|:----:|:------:|------|
| `video_url` | string | ✅ | — | 视频地址（支持 HTTP/HTTPS） |
| `frame_time` | int | ❌ | `2` | 抽取第几秒的帧作为预览背景 |
| `blur_subtitles` | bool | ❌ | `false` | 是否对预览帧底部 1/3 做高斯模糊（消除原视频字幕） |
| `blur_strength` | int | ❌ | `15` | 模糊强度，仅 `blur_subtitles=true` 时生效 |

### 响应

```json
{
  "code": 200,
  "message": "预览帧获取成功",
  "data": {
    "frame_base64": "data:image/jpeg;base64,/9j/4AAQ...",
    "video_width": 1080,
    "video_height": 1920,
    "preview_width": 540,
    "preview_height": 960
  }
}
```

| 字段 | 说明 |
|------|------|
| `frame_base64` | 可直接赋给 `<img src="">` 或 Canvas `drawImage` |
| `video_width` / `video_height` | 原始视频分辨率，用于前端计算坐标缩放比例 |
| `preview_width` / `preview_height` | 实际返回图片尺寸（固定 540×960） |

### 错误响应

```json
{
  "code": 400,
  "message": "缺少 video_url 参数",
  "data": null
}
```

## 三、接口二：提交处理接口（原接口升级）

> 新增 `subtitle_config` 字段，**其他字段不变**。

### 请求

```
POST /api/video/subtitle_img_watermark/add
Content-Type: application/json
```

```json

  "subtitle_config": {
    "font_size": 18,
    "margin_v": 74,
    "primary_colour": "#FFFF00",
    "outline": 1,
    "outline_colour": "#000000",
    "bold": 1,
    "blur_subtitles": false,
    "blur_strength": 15
  }

```

### `subtitle_config` 字段详细说明

| 字段 | 类型 | 默认值 | 范围建议 | 说明 |
|------|------|:------:|:--------:|------|
| `font_size` | int | `18` | 12 ~ 60 | 字体大小，单位为视频原始分辨率下的 px |
| `margin_v` | int | `74` | 20 ~ 300 | 字幕距视频**底部**的距离，单位为视频原始分辨率下的 px |
| `primary_colour` | string | `"#FFFF00"` | 颜色选择器 | 字体颜色，标准 `#RRGGBB` 格式，**后端自动转 ASS 格式** |
| `outline` | int | `1` | 0 ~ 5 | 描边宽度（`0` = 无描边） |
| `outline_colour` | string | `"#000000"` | 颜色选择器 | 描边颜色，`#RRGGBB` 格式 |
| `bold` | int | `1` | 0 / 1 | 是否加粗（`0` = 不加粗，`1` = 加粗） |
| `blur_subtitles` | bool | `false` | 开关 | 是否对原视频底部字幕区域做高斯模糊处理 |
| `blur_strength` | int | `15` | 5 ~ 30 | 高斯模糊强度，仅 `blur_subtitles=true` 时生效 |

> ⚠️ `subtitle_config` 整个字段可以不传，后端会使用上表中的默认值。

## 四、前端 Canvas 预览实现

### 4.1 初始化（调用一次）

```js
let bgImage = null
let scaleRatio = 1
const canvas = document.getElementById('preview-canvas')
const ctx = canvas.getContext('2d')

// 固定 canvas 显示尺寸，与预览帧一致
canvas.width  = 540
canvas.height = 960

async function loadPreviewFrame(videoUrl) {
  const res = await fetch('/api/video/subtitle/preview-frame', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ video_url: videoUrl, frame_time: 2 })
  })
  const { data } = await res.json()

  // scaleRatio：视频原始px → canvas显示px 的换算比例
  scaleRatio = data.preview_height / data.video_height  // 960 / 1920 = 0.5

  const img = new Image()
  img.src = data.frame_base64
  img.onload = () => {
    bgImage = img
    renderPreview()
  }
}
```

### 4.2 实时渲染（参数变动时调用）

```js
// config 对象与 subtitle_config 字段完全对应
let config = {
  font_size:      18,
  margin_v:       74,
  primary_colour: '#FFFF00',
  outline:        1,
  outline_colour: '#000000',
  bold:           1
}

// previewText 建议使用文案第一句（逗号/句号前截取）
let previewText = '这里展示字幕效果'

function renderPreview() {
  if (!bgImage) return
  ctx.clearRect(0, 0, canvas.width, canvas.height)

  // 1. 画背景帧
  ctx.drawImage(bgImage, 0, 0, canvas.width, canvas.height)

  // 2. 坐标换算（视频原始px → canvas px）
  const fontSize     = config.font_size * scaleRatio   // 18 * 0.5 = 9
  const marginBottom = config.margin_v  * scaleRatio   // 74 * 0.5 = 37
  const x = canvas.width / 2
  const y = canvas.height - marginBottom

  // 3. 字体设置
  ctx.font      = `${config.bold ? 'bold' : 'normal'} ${fontSize}px 微软雅黑, sans-serif`
  ctx.textAlign = 'center'
  ctx.textBaseline = 'bottom'

  // 4. 描边（先画描边，再画填充，防止描边盖住文字）
  if (config.outline > 0) {
    ctx.strokeStyle = config.outline_colour
    ctx.lineWidth   = config.outline * 2 * scaleRatio
    ctx.lineJoin    = 'round'
    ctx.strokeText(previewText, x, y)
  }

  // 5. 字体填充
  ctx.fillStyle = config.primary_colour
  ctx.fillText(previewText, x, y)
}

// 任意参数变动时调用 renderPreview，无需请求后端
document.getElementById('font-size-slider').oninput = (e) => {
  config.font_size = parseInt(e.target.value)
  renderPreview()
}
document.getElementById('margin-v-slider').oninput = (e) => {
  config.margin_v = parseInt(e.target.value)
  renderPreview()
}
document.getElementById('color-picker').oninput = (e) => {
  config.primary_colour = e.target.value  // <input type="color"> 直接输出 #RRGGBB
  renderPreview()
}
```

## 七、注意事项

1. **颜色格式**：前端统一传 `#RRGGBB`，后端自动转换为 FFmpeg ASS 格式，**前端无需处理**。
2. **坐标单位**：`font_size` 和 `margin_v` 的单位是**视频原始分辨率下的 px**（1080×1920），不是 Canvas 显示尺寸，前端渲染时需乘以 `scaleRatio`。
3. **scaleRatio 计算**：必须用接口返回的 `preview_height / video_height`，不能用 Canvas 元素的显示尺寸，防止 DPR / CSS 缩放影响。
4. **previewText**：建议截取文案第一句（第一个句号/逗号之前），让用户看到最接近真实的效果。
5. **`subtitle_config` 可选**：该字段不传时后端走默认值，不影响旧调用方。

## GET 查询全部数字人（支持名称筛选）

GET /api/material/digital-human/all/

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|name|query|string| 否 |名称筛选（模糊匹配 digital_human_name）|

> 返回示例

> 200 Response

```json
{
  "code": 200,
  "data": null,
  "message": "success"
}
```

### 返回结果

|状态码|状态码含义|说明|数据模型|
|---|---|---|---|
|200|[OK](https://tools.ietf.org/html/rfc7231#section-6.3.1)|查询成功|[ApiSuccess](#schemaapisuccess)|

## POST 数字人分页查询（POST，支持名称筛选）

POST /api/material/digital-human/paginate/

> Body 请求参数

```json

  "page": 1,
  "pageSize": 1
}
```

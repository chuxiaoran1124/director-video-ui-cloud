# 批量启动计划任务功能说明

## 概述
实现了启动计划下所有任务的功能，支持批量将任务推入 `decompose_scheduled` 队列进行异步处理。

## 实现结构

### 1. 服务层新增方法

**文件**: `material/service/A2EPlanVideoService/A2EPlanVideoTaskService.py`

#### `start_all_plan_tasks(plan_id: int) -> Dict[str, Any]`

**功能**:
- 查询计划下所有未删除的任务
- 批量启动任务（遍历调用 `start_single_task`）
- 统计成功/失败任务数
- 记录失败任务的详细错误信息
- 返回汇总结果

**参数**:
- `plan_id`: 计划ID

**返回结果示例**:
```python
{
    "plan_id": 9,
    "total_count": 5,              # 该计划下任务总数
    "success_count": 4,             # 成功启动的任务数
    "failed_count": 1,              # 失败的任务数
    "failed_tasks": [               # 失败任务详情
        {
            "task_id": 10,
            "error": "任务已在处理中或已完成，无法重复启动: task_id=10, status=1"
        }
    ],
    "success_tasks": [              # 成功任务详情
        {
            "task_id": 11,
            "sched_task_id": "abc12345"
        },
        {
            "task_id": 12,
            "sched_task_id": "def67890"
        }
    ]
}
```

**异常处理**:
- `ValueError`: 计划不存在或该计划下没有任务
- 单个任务失败不会中断整个流程，会继续处理其他任务

## 使用示例

### 请求示例
```bash
curl -X POST http://localhost:8000/api/material/plan/video/task/start-all/ \
  -H "Content-Type: application/json" \
  -d '{"plan_id": 9}'
```

### Python 请求示例
```python
import requests

url = "http://localhost:8000/api/material/plan/video/task/start-all/"
payload = {"plan_id": 9}
response = requests.post(url, json=payload)
data = response.json()

if data['code'] == 0:
    result = data['data']
    print(f"计划 {result['plan_id']} 的任务启动情况:")
    print(f"  总数: {result['total_count']}")
    print(f"  成功: {result['success_count']}")
    print(f"  失败: {result['failed_count']}")
    
    if result['failed_tasks']:
        print("\n失败的任务:")
        for task in result['failed_tasks']:
            print(f"  - 任务ID {task['task_id']}: {task['error']}")
```

### JavaScript/前端请求示例
```javascript
fetch('/api/material/plan/video/task/start-all/', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    plan_id: 9
  })
})
.then(response => response.json())
.then(data => {
  if (data.code === 0) {
    const result = data.data;
    console.log(`计划 ${result.plan_id} 的任务启动完成`);
    console.log(`总数: ${result.total_count}`);
    console.log(`成功: ${result.success_count}`);
    console.log(`失败: ${result.failed_count}`);
    
    if (result.failed_tasks.length > 0) {
      console.log('失败任务:');
      result.failed_tasks.forEach(task => {
        console.log(`  - 任务${task.task_id}: ${task.error}`);
      });
    }
  } else {
    console.error('启动失败:', data.message);
  }
});
```

## 工作流程

```
前端请求 (plan_id = 9)
  ↓
A2EPlanVideoTaskStartAllView.post()
  ↓
A2EPlanVideoTaskService.start_all_plan_tasks(plan_id)
  ↓
查询该计划下所有任务 (plan_id = 9, deleted = 0)
  ↓
遍历每个任务:
  ├─ 任务11: start_single_task(11) → 推入队列 ✓
  ├─ 任务12: start_single_task(12) → 推入队列 ✓
  ├─ 任务13: start_single_task(13) → 推入队列 ✓
  ├─ 任务14: start_single_task(14) → 推入队列 ✓
  └─ 任务10: start_single_task(10) → 已启动，跳过 ✗
  ↓
汇总结果 (成功4, 失败1)
  ↓
返回详细响应给前端
```

## 单个与批量对比

| 特性 | 单个任务 (`start_single_task`) | 批量任务 (`start_all_plan_tasks`) |
|------|-------------------------------|--------------------------------|
| 输入参数 | `task_id` (任务ID) | `plan_id` (计划ID) |
| 返回信息 | `{task_id, sched_task_id}` | 详细统计信息 |
| 错误处理 | 直接抛异常 | 捕获单个任务异常，继续处理 |
| 使用场景 | 单个任务启动 | 批量启动整个计划 |
| API 路径 | `/plan/video/task/start/` | `/plan/video/task/start-all/` |

## 关键特性

✓ **容错机制**: 单个任务失败不会影响其他任务
✓ **详细统计**: 成功/失败任务数及具体错误信息
✓ **日志记录**: 每个步骤都有详细日志便于调试
✓ **异常分类**: 明确的错误类型便于前端处理
✓ **订单处理**: 任务按ID排序处理，确保一致性

## 注意事项

1. 计划ID必须存在
2. 计划下至少需要有一个任务
3. 已启动或已完成的任务会被记录在 `failed_tasks` 中
4. 前端应该检查 `failed_tasks` 列表，了解哪些任务没有被启动
5. 即使有失败任务，已启动的任务也会继续处理

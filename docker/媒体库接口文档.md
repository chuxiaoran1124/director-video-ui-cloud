# 媒体库接口文档

> 基础路径：`/api/material/`  
> 认证方式：所有接口均需在请求头携带 `Authorization: Bearer <token>`

---

## 一、文件夹接口

### 1. 创建文件夹

| 项目 | 内容 |
|------|------|
| **路径** | `POST /api/material/folder/create/` |
| **认证** | 需要 |

**请求体 (JSON)**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `parentId` / `parent_id` | int | 否 | 父文件夹 ID，默认 `0`（根目录） |
| `folderName` / `folder_name` | string | 是 | 文件夹名称 |

**请求示例**

```json
{
  "parentId": 0,
  "folderName": "我的素材"
}
```

**成功响应**

```json
{
  "code": 200,
  "message": "创建成功",
  "data": {
    "id": 12,
    "userId": 5,
    "parentId": 0,
    "folderName": "我的素材",
    "folderPath": "/12/",
    "createTime": "2026-01-15T10:30:00Z",
    "updateTime": "2026-01-15T10:30:00Z"
  }
}
```

**字段说明 (data)**

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | int | 文件夹 ID |
| `userId` | int | 用户 ID |
| `parentId` | int | 父文件夹 ID，0 表示根目录 |
| `folderName` | string | 文件夹名称 |
| `folderPath` | string | 文件夹路径，格式 `/id1/id2/` |
| `createTime` | string(datetime) | 创建时间 |
| `updateTime` | string(datetime) | 更新时间 |

### 4. 删除文件夹

| 项目 | 内容 |
|------|------|
| **路径** | `POST /api/material/folder/delete/` |
| **认证** | 需要 |

**请求体 (JSON)**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | int | 是 | 文件夹 ID |

> ⚠️ 删除文件夹会**递归删除**其下所有子文件夹及文件（软删除）。

**请求示例**

```json
{ "id": 12 }
```

**成功响应**

```json
{
  "code": 200,
  "message": "删除成功",
  "data": null
}
```

---

### 5. 获取面包屑路径

| 项目 | 内容 |
|------|------|
| **路径** | `GET /api/material/folder/breadcrumb/<id>/` |
| **认证** | 需要 |

**路径参数**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | int | 是 | 文件夹 ID |

**请求示例**

```
GET /api/material/folder/breadcrumb/12/
```

**成功响应**

```json
{
  "code": 200,
  "message": "获取成功",
  "data": "/根目录/我的素材/"
}
```

> 面包屑返回的是文件夹名称路径，用 `/` 分隔，如 `/根目录/子文件夹1/当前文件夹/`

## 二、文件接口

### 1. 上传 / 更新文件

| 项目 | 内容 |
|------|------|
| **路径** | `POST /api/material/file/upsert/` |
| **认证** | 需要 |

**请求体 (JSON)**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `folderId` / `folder_id` | int | 是 | 所属文件夹 ID |
| `fileUrl` / `file_url` | string | 是 | 文件 URL（视频地址） |
| `previewUrl` / `preview_url` | string | 否 | 预览图 URL |
| `fileName` / `file_name` | string | 否 | 文件名，不传则从 `fileUrl` 自动提取 |
| `id` | int | 否 | 文件 ID，传入时为**更新**操作，不传为**新增** |

**新增请求示例**

```json
{
  "folderId": 12,
  "fileUrl": "https://example.com/video.mp4",
  "previewUrl": "https://example.com/thumb.jpg",
  "fileName": "我的视频"
}
```

**更新请求示例**

```json
{
  "id": 101,
  "folderId": 12,
  "fileUrl": "https://example.com/video_new.mp4",
  "fileName": "我的视频（更新）"
}
```

**成功响应**

```json
{
  "code": 200,
  "message": "上传成功",
  "data": {
    "id": 101,
    "userId": 5,
    "folderId": 12,
    "fileName": "我的视频",
    "fileUrl": "https://example.com/video.mp4",
    "previewUrl": "https://example.com/thumb.jpg",
    "fileType": ".mp4",
    "duration": 120,
    "fileSize": 12345678,
    "createTime": "2026-01-15T10:30:00Z",
    "updateTime": "2026-01-15T10:30:00Z"
  }
}
```

**字段说明 (data)**

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | int | 文件 ID |
| `userId` | int | 用户 ID |
| `folderId` | int | 所属文件夹 ID |
| `fileName` | string | 文件名称 |
| `fileUrl` | string | 文件 URL |
| `previewUrl` | string | 预览图 URL |
| `fileType` | string | 文件类型，如 `.mp4`、`.jpg` |
| `duration` | int | 视频时长（秒） |
| `fileSize` | int | 文件大小（字节） |
| `createTime` | string(datetime) | 创建时间 |
| `updateTime` | string(datetime) | 更新时间 |

## 三、通用说明

### 认证

所有接口均在 Header 中传入 Token：

```
Authorization: Bearer <token>
```

### 错误响应格式

```json
{
  "code": 400/401/500,
  "message": "错误描述",
  "data": null
}
```

### 参数兼容

所有接口均支持驼峰命名和蛇形命名两种方式，同一参数优先取驼峰：

| 驼峰 | 蛇形 |
|------|------|
| `folderId` | `folder_id` |
| `folderName` | `folder_name` |
| `parentId` | `parent_id` |
| `fileUrl` | `file_url` |
| `previewUrl` | `preview_url` |
| `fileName` | `file_name` |

### 接口速查表

| 功能 | 方法 | 路径 |
|------|------|------|
| 创建文件夹 | POST | `/api/material/folder/create/` |
| 文件夹列表 | GET | `/api/material/folder/list/` |
| 重命名文件夹 | POST | `/api/material/folder/rename/` |
| 删除文件夹 | POST | `/api/material/folder/delete/` |
| 面包屑路径 | GET | `/api/material/folder/breadcrumb/<id>/` |
| 上传/更新文件 | POST | `/api/material/file/upsert/` |
| 文件列表 | GET | `/api/material/file/list/` |
| 删除文件 | POST | `/api/material/file/delete/` |

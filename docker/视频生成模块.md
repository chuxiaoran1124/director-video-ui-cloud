## POST 创建视频任务

POST /video/task/create/

创建视频生成任务：
1) 创建本地记录（meterial_a2e_task_video）
2) 异步推入调度系统（decompose_immediate）

> Body 请求参数

```json
{
  "title": "测试视频",
  "msg": "字幕内容",
  "voice_id": "voice_001",
  "digital_human_id": "dh_001",
  "base_voice_url": "https://xxx/base_voice.mp3",
  "language": "zh",
  "speechRate": "1",
  "anchor_type": 1,
  "isSkipRs": 0,
  "video_cover_url": "https://xxx/cover.jpg",
  "user_group": "common"
}
```

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|body|body|object| 是 |none|
|» title|body|string| 否 |none|
|» msg|body|string| 否 |none|
|» voice_id|body|string| 否 |none|
|» digital_human_id|body|string| 否 |none|
|» base_voice_url|body|string| 否 |none|
|» language|body|string| 否 |none|
|» speechRate|body|string| 否 |none|
|» anchor_type|body|integer| 否 |none|
|» isSkipRs|body|integer| 否 |none|
|» video_cover_url|body|string| 否 |none|
|» user_group|body|string| 否 |none|

> 返回示例

> 200 Response

```json
{
  "code": 200,
  "data": {
    "id": 1
  },
  "message": "视频任务已提交，正在异步处理"
}
```

### 返回结果

|状态码|状态码含义|说明|数据模型|
|---|---|---|---|
|200|[OK](https://tools.ietf.org/html/rfc7231#section-6.3.1)|提交成功|Inline|

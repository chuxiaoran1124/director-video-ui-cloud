## POST 创建声音克隆任务（推荐入口）

POST /voice/create/

创建声音克隆任务：
1) 创建本地任务记录（material_a2e_task_voice）
2) 异步上传音频到 TOS
3) 推入调度系统 audio_clone

注意：该接口为 multipart/form-data，需要上传 file。

> Body 请求参数

```yaml
file: ""
name: 客服B-甜美女声
gender: female
language: zh
model: a2e

```

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|body|body|object| 是 |none|
|» file|body|string(binary)| 是 |训练音频文件|
|» name|body|string| 是 |声音名称|
|» gender|body|string| 是 |性别|
|» language|body|string| 是 |语言|
|» model|body|string| 是 |模型|

> 返回示例

> 200 Response

```json
{
  "code": 200,
  "data": {
    "id": 123
  },
  "message": "语音任务已提交，正在异步处理"
}
```

> 400 Response

```json
{
  "code": 400,
  "data": null,
  "message": "参数错误"
}
```

### 返回结果

|状态码|状态码含义|说明|数据模型|
|---|---|---|---|
|200|[OK](https://tools.ietf.org/html/rfc7231#section-6.3.1)|提交成功|[ApiSuccess](#schemaapisuccess)|
|400|[Bad Request](https://tools.ietf.org/html/rfc7231#section-6.5.1)|参数错误|[ApiError](#schemaapierror)|

## GET 任务分页查询

GET /voice/task/paginate/

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|page|query|integer| 否 |none|

|search|query|string| 否 |搜索条件 JSON 字符串。|

#### 详细说明

## POST 创建快速任务

POST /api/material/fast-task/create/

创建快速任务：
1) 创建本地记录（material_a2e_fast_task）
2) 异步上传视频到 TOS
3) 推入调度系统 decompose_quick

> Body 请求参数

```yaml
file: file://C:\Users\EDY\Videos\o0Q4KjQ5IElWRDIAu4pSSDsBEEWeD0gfgO9FQ9.mp4
name: 数字人A
title: 快速生成
gender: female

```

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|body|body|object| 是 |none|
|» file|body|string(binary)| 是 |视频文件|
|» name|body|string| 是 |数字人名称|
|» title|body|string| 是 |标签/标题|
|» gender|body|string| 是 |性别|

> 返回示例

> 200 Response

```json
{
  "code": 200,
  "data": {
    "id": 1
  },
  "message": "快速任务已提交，正在异步处理"
}
```

### 返回结果

|状态码|状态码含义|说明|数据模型|
|---|---|---|---|
|200|[OK](https://tools.ietf.org/html/rfc7231#section-6.3.1)|提交成功|Inline|

### 返回数据结构

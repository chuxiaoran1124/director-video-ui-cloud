# 云上版前端页面拆分计划

最后更新：2026-06-12
适用项目：`E:\qianduan\director-video-ui-cloud`

这份文档用于明确云上版前端后续页面拆分方式，避免继续把多个子业务堆到一个 `.vue` 文件里。

## 1. 拆分原则

- 一个页面文件只保留页面级职责
- 一个子业务块拆成一个子组件
- 一个弹窗或复杂表单尽量独立成组件
- 可复用的筛选栏、树组件、权限面板抽到公共组件层
- 拆分后优先保持原页面 URL 不变，降低联调成本

## 7. 拆分顺序建议

建议顺序：

1. 权限底座先改
2. 用户管理拆分
3. 角色权限管理新建
4. 租户管理与租户路由管理新建
5. 登录页与 404 页面重设计
6. 素材管理拆分
7. 单条视频生成拆分

说明：

- 第一阶段上线前，不强求所有业务页彻底拆完
- 但权限域页面必须从一开始就按清晰结构建设，不能再做成“大文件权限页”
- 第一阶段涉及页面在拆分和重构时，要同步修复历史乱码，并在阶段结束后做一次乱码巡检

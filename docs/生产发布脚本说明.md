### 3.1 发布前端

```powershell

```

```powershell
pwsh -File E:\qianduan\director-video-ui-cloud\deploy\发布前端到生产.ps1 -Branch main
```

### 3.2 回滚前端


## 4. 脚本会自动做什么

- 校验前端本地仓库 `origin`
- 校验已跟踪改动是否已提交
- `git push`
- 本机执行 `npm run build`
- 本机把前端源码和 `dist` 分别打包
- 上传源码包和静态资源包到生产机
- 生产机备份旧前端目录和旧 `nginx/html`
- 替换前端源码目录
- 直接刷新 `nginx/html` 挂载内容并重启 `frontend` 容器
- 访问 `https://qqxxkj.com` 做健康检查

补充说明：

- 前端现在不再依赖生产机现场重新 `docker build` 来生成页面资源。
- 这样可以避开服务器上中文静态文件名导致的 Docker BuildKit 上下文编码问题。
- 生产机前端容器会挂载 `./nginx/html:/usr/share/nginx/html:ro`，后续发版只需要替换静态资源即可。

## 3. 使用方式

### 3.1 发布前端

```powershell
pwsh -File E:\qianduan\director-video-ui-cloud\deploy\发布前端到生产.ps1
```

指定分支：

```powershell
pwsh -File E:\qianduan\director-video-ui-cloud\deploy\发布前端到生产.ps1 -Branch main
```

### 3.2 回滚前端

```powershell
pwsh -File E:\qianduan\director-video-ui-cloud\deploy\回滚前端到生产.ps1 -Ref v1.0.0
```

### 3.3 健康检查

```powershell
pwsh -File E:\qianduan\director-video-ui-cloud\deploy\生产健康检查.ps1 -Component frontend
```

## 4. 脚本会自动做什么

- 校验前端本地仓库 `origin`
- 校验已跟踪改动是否已提交
- `git push`
- 生产机拉最新代码
- 定向重建 `frontend` 容器
- 访问 `https://qqxxkj.com` 做健康检查
